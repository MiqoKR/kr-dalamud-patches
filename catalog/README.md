# 카탈로그 규칙

`kr-dalamud-updater`가 이 JSON을 내려받아 설치된 플러그인 버전과 SHA-256을 비교합니다.

- `testing.json`: 로컬 또는 제한된 환경에서 검증한 후보. 자동 설치 대상으로 사용하지 않습니다.
- `stable.json`: GitHub Release의 ZIP 이름·SHA-256·지원 대상 해시가 모두 확정된 모듈만 수록합니다.

카탈로그의 SHA-256은 패처가 원본 플러그인을 수정하기 전에 검증하는 값입니다. 값이 일치하지 않으면 패처는 중단하며, 사용자는 원본 플러그인을 재설치하거나 해당 버전 지원 릴리스를 기다려야 합니다.
