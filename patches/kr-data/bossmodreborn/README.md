# BossModReborn KR

BossModReborn `7.5.1.35` 공식 원본을 격리 복사본에서 검증했습니다.

- KR Lumina 시트 호출이 기본 언어 fallback을 사용하도록 보정합니다.
- 한섭에서 충돌하는 legacy map-effect 훅과 참조를 제거합니다.
- Patch Manager는 공식 원본 `BossModReborn.dll` SHA-256을 확인한 버전에만 적용합니다.

실제 전투·DMU 환경 검증은 별도로 진행하며, 적용 전에는 게임과 XIVLauncher·Dalamud를 모두 종료해야 합니다.
